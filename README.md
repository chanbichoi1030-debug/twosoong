# today two숭숭 (워치 알림 버전)

투숭이 일일퀘스트 + 투숭이 타임머신 PWA에, 타이머를 켜면 투숭이가 아이폰/애플워치로 알려 주는 기능을 더한 버전이에요.

## 알림이 오는 때
| 언제 | 예시 (공부) | 예시 (운동) |
|---|---|---|
| 시작하고 1분 뒤 | 📚 공부와 사투 중! | 🏃 투숭이 핫 걸 되는중! |
| 30분마다 | 📚 영어 공부 30분째! | 🏃 헬스 운동 1시간째! |
| 잠깐 멈춤 후 다시 시작하고 1분 뒤 | 📚 다시 공부와 사투 시작! | 🏃 다시 핫 걸 되는중! |
| 끝내고 기록 | ✅ 영어 공부 1시간 기록 완료! | ✅ 헬스 운동 40분 기록 완료! |

아이폰이 잠겨 있을 때 온 알림이 애플워치로 와요. 알림은 1분 정도 늦게 올 수 있어요.

## 폴더 구성
- `public/` 앱 화면 (index.html, 서비스 워커, 아이콘)
- `netlify/functions/` 알림을 보내는 작은 서버 (Netlify Functions, 매분 실행되는 예약 함수 포함)
- `netlify/lib/core.mjs` 알림 문구와 예약 로직
- `netlify.toml`, `package.json` Netlify 설정

알림용 키(VAPID)는 처음 쓸 때 서버가 스스로 만들어 Netlify Blobs에 저장해요. 따로 넣을 설정값은 없어요.
